# Локальная разработка

Прод-деплой и облачная база не требуются. Vite запускает интерфейс и локальный
адаптер для `/api/leads`, а данные сохраняются в PostgreSQL на этом компьютере.

На рабочем компьютере уже обнаружен запущенный PostgreSQL 17 на порту `5432`.

## Первый запуск

1. Скопируйте `.env.example` в `.env.local`.
2. Замените `YOUR_LOCAL_PASSWORD` на локальный пароль пользователя `postgres`.
3. Выполните `npm run db:init`. Команда создаст базу `gm_course` и таблицы.
4. Запустите `npm run dev`.

Сайт и API будут доступны через один локальный адрес Vite. Файл `.env.local`
игнорируется Git и не должен отправляться в репозиторий или переписку.

## Проверка

Заполните форму «Оставить заявку». Новая запись сохранится в локальной таблице
`leads` базы `gm_course`.

## Переезд в облако

Приложение использует стандартный PostgreSQL-драйвер. При переезде на Neon или
Supabase достаточно выполнить ту же SQL-миграцию и заменить `DATABASE_URL`;
схему и API переписывать не потребуется.

## Prodamus

Создание заказов и проверку подписи webhook можно разрабатывать локально.
Чтобы получить настоящий webhook от Prodamus на localhost, позднее понадобится
временный публичный HTTPS-туннель либо preview-деплой.
