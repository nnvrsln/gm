## Где мы

Переделываем лендинг **предзаписи** в лендинг **самого курса**. Секции
переписываются по одной. Готовы: герой (был раньше), «О курсе», «Для кого
этот курс». Обе последние переделаны в этой сессии.

Разработка идёт визуально: `npm run dev` → `http://localhost:5173/`, макет
мобильный фиксированной ширины 430px, десктопной версии нет.

### Стандарт отступов между секциями

Введён класс `.section-rhythm` в `src/index.css`:

```css
.section-rhythm { padding-top: 20px; padding-bottom: 32px; }
```

**Зазор между любыми двумя секциями = 52px.** Величина снята со стыка
«герой → о курсе», он задал тон странице. До этого зазоры разъезжались:
58 / 80 / 92 / 155px.

Асимметрия намеренная: верхний отступ у секций с фотофоном определяет, где
начинается кадр и как ложится маска растворения, — его трогать нельзя,
поэтому вся разница вынесена вниз.

Применён ко всем секциям. Единственное исключение — герой: у него свой верх
`pt-[132px]`, это первый экран. Утилита Tailwind перебивает класс, потому что
утилиты лежат в слое выше `components`.

Проверено замером после прокрутки страницы: 58 / 58 / 60px.

**Мерить надо по краске, а не по границам блоков.** Стык «о курсе → для кого»
казался больше остальных, хотя `getBoundingClientRect` давал те же 58px:
последний пункт списка опор курса нёс собственный `padding-bottom: 14px`, и
просвет от текста до надзаголовка выходил 72px против 58px на стыке с героем,
где снизу стоят кнопки с заливкой до края. Лечится `last:pb-0` на пункте
списка (`AboutSection`), парно к уже стоявшему там `first:pt-0`.

> При замерах отступов **сначала прокрути всю страницу**: непроявленные
> `data-reveal` смещены на 24px и врут в числах. На этом я один раз попался.

## Грабли, на которые уже наступили

- **React стирает класс `is-in` — элемент исчезает.** `useReveal` ставит
  `.is-in` напрямую через `classList.add`, а React при следующем рендере
  переписывает атрибут `class` целиком своей строкой. Пока `className`
  статичен, всё работает; как только он начинает зависеть от состояния
  (подсветка открытой карточки в программе), класс пропадает и элемент
  возвращается в `opacity: 0` — на экране блок просто исчезает по нажатию.
  Для таких элементов есть `.reveal-child` в `index.css`: состояние живёт на
  секции-родителе, потомок только читает его через
  `[data-reveal].is-in .reveal-child`. `data-reveal` вешать можно только на
  то, чей `className` не меняется.

- **У «Й» пропадал бревис** — заголовки выглядели срезанными сверху
  («РАЗВИВАИ СВОИ», «ГЛУБОКИИ ПОДХОД»). Причина не в обрезке: заливка идёт
  через `background-clip: text`, фон рисуется только по боксу элемента, а при
  `line-height` 0.8–0.94 бокс ниже естественной строки (38px против 52px на
  H1) — всё, что торчит выше, остаётся прозрачным. Лечится в `index.css`
  тройкой `padding-top: .18em` + `translateY(-.18em)` + `margin-bottom: -.18em`
  на `.hero-title span, .section-title`: бокс заливки растёт вверх, текст и
  поток остаются на месте. Через `margin-top` компенсировать нельзя — на
  заголовках стоят утилиты `mt-*`, а слой utilities перебивает components.

- **Tailwind не видит новую папку в `src`, созданную после старта dev-сервера.**
  Классы из неё молча не генерируются, страница выглядит «без стилей».
  Лечится перезапуском, но в `index.css` добавлена директива `@source "./"`,
  чтобы новые файлы подхватывались сразу.
- **Кнопки героя ведут в никуда.** `href="#buy"` и `href="#program"` —
  таких якорей на странице нет (есть `#about`, `#audience`, `#lead`). Оба
  главных CTA не работают. Не чинил: `#buy` логично вешать на будущую секцию
  с ценой, а `#program` — на секцию программы, которых ещё нет.

## Макетная страница с раскладками

`http://localhost:5173/variants.html` — десять вариантов секции «Для кого»
рядом друг с другом, на настоящих классах проекта.

| Файл | Роль |
| --- | --- |
| `variants.html` | вторая точка входа Vite, только dev |
| `src/variants.tsx` | React-энтри |
| `src/dev/AudienceVariants.tsx` | десять раскладок «Для кого» |
| `program.html` | третья точка входа, только dev |
| `src/program.tsx` | React-энтри |
| `src/dev/ProgramVariants.tsx` | десять раскладок «Программа курса» |
| `src/data/program.ts` | шесть модулей, тексты **черновые** |

Вторая макетная — `http://localhost:5173/program.html`. Ассеты под неё:
шесть 3D-рендеров из первой партии (`course-methodology`, `-cases`, `-growth`,
`-equipment`, `-progress`, `-analysis`), они лежали без применения — заводились
под «О курсе», там от них отказались в пользу иконок. Все переведены в WebP.

Побочный эффект макетных: Tailwind сканирует `src/dev`, и классы вариантов
попадают в прод-CSS. Сейчас это +5 КБ (около 1 КБ в gzip). Когда раскладки
выберут, папку стоит вычистить.

В прод не попадает: Vite по умолчанию собирает единственной точкой входа
`index.html`. Проверено — в `dist` только `index.html`.

Выбран вариант 03 «Зигзаг». Остальные девять оставлены: пригодятся, когда
дойдём до других секций, — там те же приёмы (постеры, стопка, мозаика,
расстановка по схеме поля).

Есть ещё опубликованная копия страницы:

Она статичная, на местных стилях не завязана — при расхождении верить надо
