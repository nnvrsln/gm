## Что это

Одностраничный лендинг онлайн-курса Гаджи Гаджиева: React 19 + Vite 7 + Tailwind 4,
чистый фронтенд без бэкенда. Весь интерфейс и все комментарии в коде — на русском.

## Команды

```bash
npm run dev        # Vite на 5173
npm run typecheck  # tsc --noEmit по src и vite.config.ts
npm run build      # typecheck, затем vite build
```

Тестов в проекте нет. `npm run typecheck` — единственная проверка перед коммитом;
она обязана быть зелёной, поскольку `build` её вызывает.

Отдельный инструмент: `node scripts/to-webp.mjs [файл…]` — перегоняет PNG из
`src/assets` в WebP. Не часть сборки, гоняется руками, когда заказчик приносит новые
кадры.

## Архитектура

**Один TypeScript-проект.** `tsconfig.json` покрывает `src` и `vite.config.ts`.
Второго проекта под серверный код больше нет: `tsconfig.api.json` удалён вместе с
`api/`.

**Сборка — одна страница.** Точка входа `index.html` → `src/main.tsx` → `App.tsx`.
Макетные страницы, на которых примерялись подачи слайдов, удалены; если понадобится
новая, она заводится парой «`имя.html` в корне + `src/имя.tsx`» и в прод-сборку не
попадает (Vite по умолчанию берёт единственной точкой входа `index.html`).

**Секретов и переменных окружения в проекте нет.** Появится серверный секрет — его
нельзя добавлять с префиксом `VITE_`, иначе он уедет в бандл.

## Фронтенд

- **Мобильный макет фиксированной ширины.** `App.tsx` оборачивает всё в
  `max-w-[430px]`; десктопной версии нет, верстать секции нужно под эту ширину.
- **Секции** — плоский список компонентов в `App.tsx`, каждая сама себе `<section>`
  с `px-5`. Шапки нет: навигация по секциям живёт в подвале.
- **Анимации появления секций нет** — снята 31.08 по просьбе владельца. Библиотек
  анимации в проекте нет вообще.
- **Прокрутка по якорям плавная** (`scroll-behavior: smooth` под
  `prefers-reduced-motion`). Важно: слой `CourseBackdrop` обязан лежать внутри
  клипующей коробки по размеру обёртки — иначе обёртка становится прокручиваемой, и
  переход по якорю уносит содержимое секций вверх (см. журнал 01.09).
- **Дизайн-токены** — `@theme` в `src/index.css` (цвета `pitch/panel/blood`, шрифты,
  кривые `--ease-mass` / `--ease-snap`). Tailwind-конфига нет, всё через CSS.
- Комментарии в `index.css` фиксируют неочевидные решения с измерениями
  (трекинг Bebas только целыми пикселями, маски растворения краёв фото в px, а не в
  процентах). Перед правкой этих блоков — прочитать комментарий рядом.
- Шрифты локальные (`src/assets/*.ttf|woff2`), внешних запросов со страницы нет.
- Тексты-данные вынесены в `src/data/*.ts` (`ACHIEVEMENTS`, аудитория, программа,
  тарифы, FAQ, правовые ссылки), картинки импортируются в этих же файлах.
- В `src/assets` лежат только используемые файлы: после чистки 01.09 каждый ассет
  оттуда действительно попадает в сборку.

## Импорт конфигурации

В системе найден конфиг OpenAI Codex (`~/.codex/config.toml`). Если хочешь перенести
из него MCP-серверы, команды, агентов или инструкции — ответь `/import`: команда
покажет, что импортируемо, и выдаст digest; затем `/import --yes=<digest>` применит
пользовательские элементы.
